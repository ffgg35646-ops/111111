# منصة التدريب والمحاكاة السريرية

منصة عربية RTL للتعليم والتدريب والاستشارات المهنية، مع مسار مستقل لمحاكاة الحالات السريرية باستخدام الذكاء الاصطناعي والواقع الافتراضي.

## الحالة الحالية

هذا المستودع بدأ بهيكل Next.js تأسيسي، ثم أضيفت إليه وحدات أولية للشخصيات السريرية، الصوت، تقييم لغة الجسد، الغرف المشتركة، وملفات الكفاءات. لا تزال بعض الوحدات تحتاج إعداد الخدمات الخارجية وربط محرك Unreal/OpenXR والمصادقة المؤسسية قبل التشغيل الإنتاجي.

## الوحدات المستهدفة

- إدارة المستخدمين والأدوار والصلاحيات.
- الأكاديمية: الدورات المسجلة والمباشرة والاختبارات والشهادات.
- تكامل Zoom للفصول وتأجير القاعات.
- الاستشارات المهنية والعلاجية مع فصلها عن التدريب والمحاكاة.
- متجر الكتب والمواد المعرفية.
- إدارة المحتوى العلمي والمقاييس المرخصة.
- محرر سيناريوهات الحالات السريرية.
- طبيب نفسي افتراضي سعودي واحد ثابت، بهوية وصوت موحدين في كل المسارات، مع استوديو لربط موديل بشري فوتوريالي.
- محرك AI للمحادثة النصية والصوتية مع تمرير سياق المسارات والمقررات وأدوات التدريب المتاحة.
- عميل VR مستقل باستخدام Unreal Engine وOpenXR.
- تقييم أداء المتدرب وربط النتائج بملف الكفاءات.
- ورقة دراسة حالة إلزامية داخل المحاكاة: المشكلة والسياق والملاحظة ونقاط القوة والفرضيات والمعلومات الناقصة وخطة الإحالة واختيار نموذج تدريبي؛ تحفظ مع سجل الجلسة لمراجعة المشرف.
- غرف إشراف متعددة المستخدمين.

## الطبيب الافتراضي السعودي

تعتمد المنصة طبيباً نفسياً افتراضياً سعودياً واحداً، يعمل كمدرب ومشرف تعليمي في جميع التخصصات والحالات. لا يتقمص دور الأب أو الأم أو الطفل أو المراجع، ولا تتغير هويته بتغير الفئة العمرية للحالة. سياق الجلسة يضم الحالة الحالية وبيانات المسار والمقررات وأهداف التعلم وأدوات التدريب المدرجة في فهرس المنصة.

يوجد حالياً نموذج بشري ثلاثي الأبعاد مبدئي يعمل افتراضياً في استوديو الطبيب والمحاكاة: رجل بالغ بهيكل حركي، حركات مسجلة، أشكال وجه ARKit، ورمش وحركة رأس وعينين، مع تحريك الفك بحسب شدة الصوت. هذا النموذج الأساسي بملابس رسمية عامة لا يمثل بعد التصميم السعودي النهائي بالثوب الأبيض والمعطف الطبي. يمكن استبداله دون تغيير منطق التفاعل عبر `NEXT_PUBLIC_SAUDI_DOCTOR_AVATAR_MODEL_URL` بملف GLB/GLTF معتمد ومطابق للهوية. اطلع على `docs/third-party-avatar-notices.md` لمصدر النموذج وترخيصه. نسخة Unreal تحتاج Blueprint MetaHuman معتمد وربط حركة الوجه والصوت بصورة مستقلة. رفع ملف من صفحة `/characters` محلي للمعاينة ولا يحفظه على الخادم.

راجع `docs/saudi-family-avatar-assets.md` لمواصفات الأصل ومسار ربطه.

## حدود المعرفة والصوت

يتم تمرير محتوى المسار والمقررات والأهداف وأدوات التدريب المتاحة في فهرس المنصة إلى سياق المحادثة. لم تتم إضافة قاعدة استرجاع دلالي شاملة لمستندات وملفات الدومين بعد؛ ولا ينبغي للطبيب الادعاء بالاطلاع على ملفات لم تُمرر إليه. الصوت الحي يستخدم `CLINICAL_REALTIME_VOICE` (الافتراضي `cedar`) مع توجيه للنطق بلهجة سعودية بيضاء؛ يجب اختبار النطق الفعلي، فاسم الصوت المدمج لا يضمن بحد ذاته لهجة سعودية أصلية.


## مبدأ عمل الطبيب الافتراضي

الطبيب الافتراضي لا يعتمد على نص محفوظ أو شجرة حوار جامدة. تتغير مادة الشرح وسياق الحالة والأهداف التدريبية حسب المسار الذي يختاره المتدرب، بينما تبقى هوية الطبيب واحدة. لا يجوز له اختراع تاريخ حالة أو نتائج مقاييس أو مراجع غير موجودة في السياق المرفق.

## الحوكمة والسلامة

- الاستخدام الأساسي محاكاة تعليمية، وليس أداة تشخيص ذاتي أو تشخيص آلي للمرضى الحقيقيين.
- لا يصدر النظام تشخيصاً نهائياً أو يصف علاجاً دوائياً مستقلاً.
- سيناريوهات الخطر تتضمن بروتوكول إيقاف وإحالة بشرية معتمد.
- المقاييس والاختبارات لا تضاف إلا بعد التحقق من حقوق الاستخدام والترخيص.
- بيانات المتدربين وملفات الاستشارات منفصلة بصلاحيات وتدقيق وصول مستقل.
- التسجيل الصوتي أو المرئي لا يتم دون موافقة واضحة.

## إعداد مدير المنصة والحسابات

1. أضف `MONGODB_URI` و`PLATFORM_SESSION_SECRET` و`PLATFORM_ADMIN_EMAIL` إلى متغيرات البيئة. اجعل `PLATFORM_SESSION_SECRET` قيمة عشوائية مستقلة بطول 32 حرفاً أو أكثر.
2. أنشئ تجزئة كلمة مرور المدير محلياً عبر `node scripts/hash-platform-password.mjs`، ثم ضع الناتج في `PLATFORM_ADMIN_PASSWORD_HASH`. لا تضع كلمة المرور نفسها في ملف البيئة ولا في Git.
3. بعد أول دخول، افتح `/platform-admin/users` لإنشاء حسابات المشرفين والمدربين والمتدربين والمستشارين. تُحفظ كلمات المرور كتجزئات scrypt ويُطلب تغيير كلمة المرور المؤقتة عند أول دخول.
4. احمِ متغيرات البيئة في لوحة الاستضافة، واستخدم HTTPS. لا تشارك الجلسات أو بيانات الدخول.

## التشغيل المحلي

يتطلب Node.js 20.19 أو أحدث.

```bash
npm install
npm run dev
```

## ملاحظات

- لا يوجد نشر تلقائي أو إعداد Vercel في هذه المرحلة.
- لم تتم إضافة أي شعار أو هوية تجارية.
- الغرف الحية تتطلب إعداد LiveKit، والتقارير تتطلب MongoDB Atlas.
- المحادثة الصوتية الثنائية الاتجاه عبر Realtime تتطلب OPENAI_API_KEY على الخادم؛ مفتاح AI Gateway المستخدم للمحادثة النصية لا يستبدل هذا المفتاح في مسار Realtime الحالي. اضبط `CLINICAL_REALTIME_VOICE` لاختيار الصوت المدمج، و`NEXT_PUBLIC_SAUDI_DOCTOR_AVATAR_MODEL_URL` لملف موديل الطبيب المنشور.
- تمت إضافة أساس مصادقة للحسابات الفردية: كلمات مرور مجزأة باستخدام scrypt، جلسات JWT داخل HttpOnly cookies، أدوار مدير/مشرف/مدرب/متدرب/مستشار، إنشاء وتعطيل الحسابات، تغيير كلمة المرور المؤقتة عند أول دخول، وسجل تدقيق إداري. لم تتم إضافة MFA أو SSO أو التحقق من البريد أو استعادة كلمة المرور بعد.
- تكامل Unreal/OpenXR يجب أن يرسل حالة المشهد وقياسات VR عبر Data Channel وفق الدليل.
- راجع docs/supervision-and-competency-setup.md لإعداد مفاتيح LiveKit وMongoDB ومتطلبات الأمان.
